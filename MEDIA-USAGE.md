# Условия использования видео-примера

Видео `examples/headphones/demo.mp4`, монтажные сегменты в
`examples/headphones/assets/video/`, изображение и голос автора предоставлены
исключительно как учебный пример работы с HyperFrames.

Разрешено локально смотреть материалы, изучать композицию и выполнять локальный
тестовый рендер для понимания конвейера.

**Без предварительного письменного разрешения владельца проекта запрещено
публиковать, распространять, пересылать, повторно загружать или использовать
видео, его фрагменты, извлечённые кадры, изображение и голос автора в других
роликах, рекламе, презентациях, обучающих материалах и иных проектах.** Нельзя
использовать эти материалы для обучения моделей, клонирования голоса или
создания цифрового двойника без отдельного разрешения.

Доступ к репозиторию, скачивание файлов, указание авторства или отсутствие
коммерческой цели не заменяют разрешение владельца. Для согласования свяжитесь
с владельцем через GitHub или уже согласованный канал связи. Не размещайте
сам ролик или его кадры в публичном issue при запросе разрешения.

Для собственных публикаций используйте свои съёмки и звук. Изученные методы
монтажа можно применять к своим материалам в рамках условий `LICENSE`.

Все права на авторские медиа сохраняются за владельцем. Правила действуют
и при последующем изменении видимости репозитория на public.
