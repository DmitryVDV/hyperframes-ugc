# Пример: обзор наушников

Откройте Claude Code в корневой папке проекта и напишите:

```text
Покажи пример
```

Claude подготовит необходимые инструменты, запустит HyperFrames Studio и даст
ссылку на localhost. Откройте ссылку в браузере и включите воспроизведение.
Все команды запуска выполняет Claude.

[Готовое видео](demo.mp4) можно посмотреть и отдельно. Это учебный обзор
наушников KZ ZS10 Pro2: 13 видеосегментов, 109,63 секунды, титры и подсветка
слов по речи. Композиция — 1080×1920, 30 fps; готовый `demo.mp4` — уменьшенная
копия 720×1280 с речью без музыкальной подложки.

Чтобы сделать свой ролик, вернитесь к
[шагу 5 основной инструкции](../../README.md#5-запустите-инструкцию-для-своего-ролика).
Claude начнёт с вопросов и будет использовать ваши съёмки.

**Это видео, его фрагменты, кадры, лицо и голос нельзя использовать в других
материалах или распространять без предварительного письменного разрешения
владельца.** Разрешены локальное изучение и тестовый рендер.
[Условия использования](../../MEDIA-USAGE.md).

## Сведения для Claude Code

- CLI закреплён в `package.json` на 0.8.140. Не обновляй пример автоматически.
- Для Studio используй `preview --background`, проверь `preview --status` и
  HTTP-ответ, затем выдай URL `/#project/headphones` на фактическом порту.
- HTML и субтитры: `index.html`; слова караоке: `assets/wipe-words.js`.
- Дизайн: `frame.md`, `assets/tokens.css`; движение: `assets/motion.js`.
- Монтажные сегменты в `assets/video/` очищены от исходных метаданных и глав.
  Они сохранены без повторного сжатия. При изменении нарезки пересчитай слова.
- Для разрешённого локального тестового рендера используй один worker и
  проверь готовый MP4. Не меняй медиа примера ради нового ролика.
