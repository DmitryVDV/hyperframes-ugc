# Дизайн примера — «Цех»

Холст: 1080×1920, 30 fps. Цвета: фон #17181A, текст #EDEAE3,
второстепенный текст #A6A29B, акцент #E0DD1F. Источник токенов — assets/tokens.css.

Заголовки: Alumni Sans Black 900. Кикеры: JetBrains Mono 700, 26 px.
Плашки: Golos Text 700. Караоке: Alumni Sans Black 900, единый размер 58 px;
фраза видна целиком, подсветка меняет цвет слов по данным assets/wipe-words.js.
Смена фраз жёсткая. Углы прямые, основной фон плашки тёмный полупрозрачный.

Рабочие безопасные поля для нового монтажа: сверху 220, снизу 480,
слева 72, справа 180 px. Полоса субтитров x=72…900. В сохранённом примере
контейнер караоке имеет bottom=470; это фактическое значение исходного HTML.
Учитывайте актуальный интерфейс площадки при подготовке своего ролика.

Движение: вход 0,52 с power4.out, шаг 0,08 с, выход 0,30 с power2.in
с гашением. Библиотека движений — assets/motion.js.
