# Сторонние ресурсы

Собственные условия `LICENSE` и `MEDIA-USAGE.md` относятся к материалам владельца
проекта и не заменяют лицензии сторонних правообладателей.

| Ресурс | Использование | Источник и условия |
| --- | --- | --- |
| HyperFrames | CLI, установленный через npx; его исходники не включены | [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes), Apache-2.0 |
| GSAP 3.14.2 | Загрузка с CDN в композиции; библиотека не включена | [GSAP](https://gsap.com/), [Standard License](https://gsap.com/community/standard-license/) |
| Alumni Sans | AlumniSans-Black.ttf | [Google Fonts](https://github.com/googlefonts/alumni), SIL OFL 1.1; текст в assets/fonts/OFL-AlumniSans.txt |
| Golos Text | Bold и ExtraBold | [Google Fonts](https://github.com/googlefonts/golos-text), SIL OFL 1.1; текст в assets/fonts/OFL-GolosText.txt |
| JetBrains Mono | Bold | [JetBrains](https://github.com/JetBrains/JetBrainsMono), SIL OFL 1.1; текст в assets/fonts/OFL-JetBrainsMono.txt |

Пути `assets/fonts/` в таблице относятся к `examples/headphones/`.
Шрифтовые файлы скопированы без изменения. Лицензия JetBrains Mono содержит
стандартный текст SIL OFL 1.1 с указанием правообладателя JetBrains Mono.

Музыкальные файлы рабочей версии не включены: источник лицензии не сохранён.
Звуковая дорожка demo.mp4 заново собрана из речи монтажных сегментов,
без музыкальной подложки. Неиспользуемый установленный registry-компонент
caption-clip-wipe не включён; караоке реализовано непосредственно в index.html.
