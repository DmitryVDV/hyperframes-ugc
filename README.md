# Делаем ролики в Claude Code с GLM и HyperFrames

Свои съёмки → вопросы от Claude → согласованный сценарий → монтаж и субтитры → готовый MP4.

**Мы делали эти ролики в Claude Code, а моделью была китайская GLM от Z.ai.** HyperFrames собирает видео. Вы общаетесь с Claude обычными словами: он устанавливает инструменты, разбирает исходники, запускает просмотр и делает рендер.

## Почему я выбрал GLM или KIMI

1. **Claude Code можно скачать бесплатно**, но для обычного подключения моделей Claude нужны аккаунт Anthropic и оплаченный доступ. Россия не входит в [список поддерживаемых стран Anthropic](https://www.anthropic.com/supported-countries), поэтому для пользователей из России есть риск ограничения доступа и блокировки аккаунта. Бесплатная установка программы сама по себе не даёт бесплатного доступа к моделям Claude.
2. **С GLM и KIMI у меня нет проблем с блокировками.** Они подключаются к Claude Code через своих провайдеров: используется их аккаунт и ключ, а регистрация в Anthropic для такого подключения не нужна. GLM можно оплатить картой **UnionPay**. В [моей инструкции, в разделе об оплате](https://github.com/DmitryVDV/china-models#оплата-подписок), есть также быстрый способ оформить иностранную виртуальную карту и пополнять её в рублях через СБП.
3. **Для задач монтажа GLM прекрасно справляется — проверил на себе.** Ролик в этом репозитории мы делали именно с GLM в Claude Code: модель помогала разбирать материал, собирать монтаж, титры и субтитры через HyperFrames. Это мой практический опыт, на котором построена инструкция.

## 1. Установите Claude Code и подключите GLM

Откройте [мою инструкцию по установке Claude Code с KIMI и GLM](https://github.com/DmitryVDV/china-models). Выберите **GLM** и раздел для своей системы:

- **Windows:** выполните установку из инструкции в PowerShell, подключите свой ключ и запустите Claude Code.
- **macOS:** выполните установку из инструкции в Terminal, подключите свой ключ и запустите Claude Code.

GLM подключается через API — скачивать модель на компьютер не нужно. Ключ вводится локально по инструкции. Для повторения нашего варианта нужен доступ к GLM; точная версия модели исходной сессии не записана.

## 2. Скачайте проект и откройте его в Claude Code

На странице этого репозитория нажмите **Code → Download ZIP** и распакуйте архив. Откройте Claude Code **в распакованной папке `hyperframes-ugc-main`**: порядок запуска из нужной папки есть в инструкции выше. В этой папке должны быть `README.md`, `CLAUDE.md` и `VIDEO-WORKFLOW.md`.

Если Claude уже открыт в другой папке, напишите ему:

```text
Я скачал проект hyperframes-ugc. Помоги открыть его в Claude Code.
Спроси, где лежит распакованная папка, и дай один следующий шаг для моей системы.
```

## 3. Попросите Claude подготовить HyperFrames

Вставьте в Claude Code:

```text
Прочитай CLAUDE.md и подготовь этот проект для работы с HyperFrames.
Сам проверь компьютер, установи недостающие инструменты и навыки HyperFrames.
Команды выполняй сам. Когда всё будет готово, сообщи об этом.
```

Claude сам проверит и установит нужные программы. Если система или Claude Code запросят разрешение на установку, подтвердите его; системный пароль вводите только в системном окне. Если потребуется перезапустить Claude для подключения навыков, он объяснит один следующий шаг.

## 4. Посмотрите пример

Напишите в Claude:

```text
Покажи пример
```

Claude запустит HyperFrames Studio на вашем компьютере и даст проверенную ссылку на **localhost**. Откройте её в браузере: там можно посмотреть монтаж, титры и субтитры учебного ролика о наушниках. Сервер останется включённым для просмотра.

Готовое видео также лежит в [examples/headphones/demo.mp4](examples/headphones/demo.mp4). [Подробнее о примере](examples/headphones/README.md).

## 5. Запустите инструкцию для своего ролика

Скопируйте свои исходные видео в папку `footage` внутри скачанного проекта или оставьте их в другой папке — Claude спросит, где они находятся.

Вставьте этот запрос:

```text
Создай мой ролик по инструкции VIDEO-WORKFLOW.md.
Сначала задай мне вопросы: что за ролик, для кого он и где лежат исходники.
Задавай не больше двух вопросов за раз и веди меня по шагам.
Сам анализируй файлы, распознавай речь и выполняй технические команды.
Сценарий, музыку и стиль согласуй со мной до монтажа.
Покажи результат на localhost. Рендери только после моего одобрения превью.
```

Claude начнёт с вопросов, изучит материал и предложит подходящую длину. Затем покажет сценарий из вашей речи и спросит о музыке и оформлении. Вы проверяете и отвечаете обычными словами, например:

```text
Сценарий согласован. Музыка не нужна, стиль — как в примере.
```

После сборки Claude даст ссылку для просмотра. Правки тоже можно описывать словами:

```text
Сделай субтитры крупнее и убери последнюю плашку.
```

Когда результат вас устраивает:

```text
Превью одобряю. Рендери финальный MP4.
```

Claude выполнит рендер, проверит готовое видео и скажет, где лежит файл. Ваши проекты создаются в `work/`, учебный пример сохраняется отдельно.

## Что лежит в проекте

- [CLAUDE.md](CLAUDE.md) — правила для Claude: подготовка, просмотр примера и начало работы через вопросы.
- [VIDEO-WORKFLOW.md](VIDEO-WORKFLOW.md) — подробная инструкция на английском для агента, который выполняет монтаж.
- [examples/headphones/](examples/headphones/) — рабочий учебный пример и готовое видео.
- `footage/` — папка для ваших исходников; `work/` — папка для созданных Claude проектов.
